# Aeolus: design reference

The operator console was designed in Claude Design: [Fleet operator console v1](https://claude.ai/artifact/Wq1HqccJjQtwNyd6KvuSHg) (desktop and mobile).

The canvas is a reference for look and feel only. Behaviour, states and copy rules come from [blueprint.md](blueprint.md). Where the canvas and the blueprint disagree, the blueprint wins.

The web package is built with atomic design: shadcn/ui on Base UI as atoms, composed into molecules, organisms and page templates. The canvas is not ported screen by screen.
