## Key decisions

- Rate limit counts failed `register` attempts only, so starting many sessions from one address is never throttled.
- Deregister spends the secret: one rule for every lease end; a prompt left in a transcript cannot reclaim the ship.
- Lost `register` reply: no retry mechanism in v1; usage decides priority.
- Reads carrying the console cookie from a sibling site may extend the session; only mutations need the Origin check.
- Slice 4 prompt leaves what `inReplyTo` must refer to and how the 64 KB is measured as questions for the session.
