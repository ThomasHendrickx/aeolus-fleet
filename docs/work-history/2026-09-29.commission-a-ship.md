## Goal

The operator (argo) can commission an agent ship and hand out its starting prompt.

## Build

- Commission ship (requires `fleet:manage`): name, type, optional note.
  - Name is a handle: lowercase letters, digits, hyphens, max 48; unique among non-retired ships in the fleet; reusable after retirement; `argo` reserved.
  - Type is a free label with the same handle rules.
  - Kind `agent`, scopes `messages:send` and `messages:receive`, stored with the ship at creation.
  - The ship starts in Awaiting crew. Commissioning also issues the first starting prompt (blueprint, "Launch a ship" step 2).
- Get starting prompt (requires `fleet:manage`): only while the ship awaits crew.
  - Creates a new `aeolus_sk_v1_<random>` secret, stored as SHA-256, and invalidates any earlier one: at most one valid secret per ship.
  - Returns the prompt once; the secret is never readable again.
  - The ship exposes whether an unclaimed prompt is outstanding and when it was issued, so the console can ask for confirmation before replacing it (the confirmation itself is a UI concern).
- Placeholder prompt text: server URL, ship id, secret. The real text is drafted in slice 8.
- List the fleet (requires `fleet:read`): per ship its name, type, status, and prompt state (issued when, claimed or not). argo included.
- Events in the same transaction: ship commissioned, starting prompt issued, credential revoked (when a prompt replaces an earlier one).
- Web: a bare, unstyled page (signed in as argo) listing the fleet, a commission form, and a "get starting prompt" action that shows the prompt once with a copy button and asks for confirmation when an unclaimed prompt is still out.

## Key decisions

Not dictated by the docs:

- **Handle.** Exactly the blueprint's rule: 1 to 48 lowercase letters, digits or hyphens. No further shape rule (0016); input that does not match is refused, never trimmed or lowercased. One pattern in common, used by the domain and the form.
- **Note.** Trimmed, empty means none, at most 500 characters.
- **Type `operator`** is not reserved for agent ships (0016).
- **The list** includes retired ships, with status retired, and shows no note (the slice asks for name, type, status and prompt state).
- **argo's prompt state** is its secret: issued at init or replacement, claimed at the first sign-in.
- **Statuses** `awaitingCrew`, `crewed`, `retired`, like the other camelCase closed sets.
- **Events.** `ShipCommissioned` carries name, type and kind, as for argo; `StartingPromptIssued` and `CredentialRevoked` carry the credential id. The actor is the calling ship.
- **Refusals.** Invalid name, type or note: BAD_REQUEST. Name taken, not awaiting crew: CONFLICT. Unknown ship, or a ship of another fleet: NOT_FOUND. argo's prompt: FORBIDDEN, as for its other permanence rules.
- **Concurrency.** A commission takes a transaction advisory lock on the fleet and the name before its lookup. A starting prompt locks the ship `FOR NO KEY UPDATE`, then the secret, then reads the lease: the fleet's lock order (ship, credential, console sessions, leases). `FOR UPDATE` would block the foreign key checks of rows pointing at the ship; a test proved the deadlock.
- **Prompt text.** Placeholder lines: fleet URL, ship id, ship secret, and that it is a placeholder.
- **`PUBLIC_URL`**, required, `http` or `https`, used as given. The server commands need it too, because they share the configuration.
- **API.** `fleet.commission` and `fleet.getStartingPrompt` are mutations returning `{ shipId, prompt }`; `fleet.list` returns `startingPrompt: { issuedAt, isClaimed } | null` per ship.
- **Registry reads secret dates** through its own `FleetListing` port, as it reads deliveries through `InFlightDeliveries`.
- **Web.** `/` is the fleet page; `system.ping` stays in the API but no page uses it. The form uses React Hook Form with common's schema. The confirmation is inline, not `window.confirm`. A prompt stays until Done or leaving the page. Next bundles common's built package (Turbopack resolves no custom export conditions, and common's source imports end in `.js`), so `npm run dev` and the end-to-end harness build common first.
