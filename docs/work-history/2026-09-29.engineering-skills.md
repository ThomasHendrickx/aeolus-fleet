## Key decisions

- Adapted from the Hemma skills, not copied: no Inngest, i18n or analytics; core uses factory-function use cases like `createPing`, and hand-written in-memory fakes instead of mocks.
- Domain outcomes are result values with named error kinds; exceptions only for system failures.
- Aggregates are pure functions over plain data that return new state plus raised events; they never read the clock or generate ids.
- Red commits are allowed but only green heads are pushed, so CI stays green.
- Storybook is deferred to the console work, as Thomas decided.
