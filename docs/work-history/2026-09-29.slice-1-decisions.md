## Key decisions

- Of the two options Thomas gave for `argo` (a type, or one ship whose sign-in takes the lease over), the single ship with takeover was written down: the name `argo` implies one ship, and it keeps one lease rule.
- Scopes live with the ship and a console session inherits `argo`'s, which covers "given at login" without a second store.
- Fleet init is a server command, not a public setup page, because the first visitor of a public setup page would own the fleet.
- The console session's lease location is `OTHER` / `web console`.
- The dismiss status sits on the delivery, which in v1 is one per message.
