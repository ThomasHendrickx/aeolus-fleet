## Real parts and reproducibility

The checked-out ui package supplies Button and Badge (`parts.jsx` points directly to the real files) and Harbour with its real tiles and counters. The approved onboarding M15/M18 question renderer is reused with fixture props. No live app container, API or credentials are included. The shell and simulated terminal compose these parts in the approved onboarding look. The styling imports `packages/ui/src/theme.css` and its tokens; `layout.css` follows the approved onboarding composition. Reference: approved onboarding PR #1925, commit `4f124318cf8e2ed8288d9a8f6fb95e03ed00c7e4`.

The mockup sources are documentation tooling, not a site implementation. To regenerate from the repository root, use `MOCKUP_TOOLS=<npm-tool-directory> node docs/design/linear-demo/mockups/build.mjs`. That directory needs React, React DOM, Base UI, esbuild, Tailwind CSS/CLI, Lucide React, class-variance-authority, clsx and tailwind-merge. Generated HTML stays useful without installing anything.
