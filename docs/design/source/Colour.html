Colour

Neutrals follow shadcn/ui names so the stock components theme themselves. The brand accent is --primary (a deep slate blue, light blue in dark mode); --accent keeps its shadcn meaning as the neutral hover surface. Status colour lives in five tone families; every ship status and delivery state maps to exactly one of them, and always carries an icon and a label as well.
