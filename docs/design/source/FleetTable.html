FleetTable

The fleet overview list: one calm 48 px line per ship. Columns in order of importance: name (with the operator chip, flagship chip or SquadronTag), status, report, runs on (harness and location kind), model, last seen (icon only). argo sorts first and never reports. Every action lives in the row menu (ghost xs button, last column); at most one next step shows in the Report cell, only for ships awaiting crew, released ships and silent members. Type and inbox counts are not in the row: Type stays a filter, open deliveries live in the Pending deliveries card and on the ship page. With squadrons off there is no Squadron filter, flagship chip or SquadronTag.
