ModelTag

What the ship’s session last stated it runs on, exactly as stated. An AI model id (claude-opus-5-5, gpt-6-sol) gets the sparkles mark on --secondary. Software ships state their package; the console treats a value that starts with @ or ends in @x.y.z as software: package mark, dashed outline, muted text. On desktop hover a Tooltip shows the full value and when it was stated, so a truncated package stays readable; phone has no hover. Empty for argo and ships without a session; “Not stated yet” for a crewed ship that has not sent anything.
