CrewLineBlock

The one line that crews a ship from Claude Code with the aeolus plugin: /aeolus:crew, fleet URL, ship id, secret. It carries the secret, so it is shown once, like the starting prompt; getting a new one stops the old one working. For a squadron member it comes with the launch note from its template, which says where to start the session.
