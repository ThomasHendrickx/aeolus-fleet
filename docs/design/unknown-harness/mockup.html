Unknown harness (aeolus-fleet#1408)

A crewed agent ship whose session stated no harness. Before: it reads as Claude Code when something filled in the default, or the harness is silently left out. After: nothing fills in a harness; where the console shows one (FleetTable Runs on, the ship page's Location cell) an unknown one shows a small label in the attention tone, warning icon and words carrying it, never colour alone. Its title says why: "The session stated no harness: a fault in Aeolus." Console ships (argo, viewers) and trierarchs are unchanged.
