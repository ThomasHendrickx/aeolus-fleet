# argo's inbox mockups

Screens for [#1571](https://github.com/ThomasHendrickx/aeolus-fleet/issues/1571), on the design in [`../README.md`](../README.md): AI1 to AI9 as answered. Mockups only; they decide no behaviour.

The Compact look ([ui-package mockups](../../ui-package/mockups/README.md)), on Bridge as approved ([Bridge mockups](../../bridge/mockups/README.md)). Each HTML file stands alone, with the tokens, the Compact kit and the Geist fonts inlined; each PNG is that file rendered in Chromium at 1x.

| File | What it shows |
| --- | --- |
| [bridge.html](bridge.html), [bridge.png](bridge.png) | Before: Bridge home as approved, nothing of argo's. After: the argo section and its own count, apart from the person's own; then a message done at argo by someone else, gone for everyone |
| [slack.html](slack.html), [slack.png](slack.png) | Before: only the person's own. After: a post marked Waits at argo, not you, with one button to the console as argo; then edited to Done at argo |
| [wake.html](wake.html), [wake.png](wake.png) | Before: the person's own wake only. After: web push and email saying something waits at argo, apart from the person's own wake |

Desktop light and dark and phone light and dark for every after. Slack, the system notifications and the mail app are drawn roughly in their own looks; only the content is Aeolus's.
