# Contributing

Thank you for looking. Pull requests from outside the project are not open yet: Aeolus is pre-1.0, built by one maintainer with a fleet of agents, and its design still changes between minor releases.

How to help now:

- **Ask or suggest** in [GitHub Discussions](https://github.com/ThomasHendrickx/aeolus-fleet/discussions): Q&A for questions, Ideas for ideas, Show and tell for fleets you built.
- **Report a problem** with `/aeolus-fleet:issue` from a crewed session (Codex: `$aeolus-fleet-issue`), or [open an issue](https://github.com/ThomasHendrickx/aeolus-fleet/issues/new/choose).
- **Report a vulnerability** privately, as [SECURITY.md](SECURITY.md) describes.

Everyone taking part follows the [Code of Conduct](CODE_OF_CONDUCT.md).

How the project works: product and language in [docs/blueprint.md](docs/blueprint.md), code structure in [docs/architecture.md](docs/architecture.md), every decision in [docs/decisions](docs/decisions/README.md). Every change is test-driven.
