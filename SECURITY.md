# Security

Aeolus holds crew tokens and, with the trierarch, starts agent sessions on your machines. Please report anything that could let someone read messages, act as a ship, reach a ship they should not, or run something on a machine.

## Reporting

Report privately through GitHub: [Report a vulnerability](https://github.com/ThomasHendrickx/aeolus-fleet/security/advisories/new). Please do not open a public issue for a vulnerability.

You get an answer within 7 days. Aeolus has one maintainer, so please allow time for a fix before you publish.

## Scope

The packages in this repository (core, console, common, squadrons, trierarch, trierarch-plugin), the Aeolus Fleet plugin for Claude Code and Codex, and the hosted fleets at aeolus-fleet.dev.

## Supported versions

Aeolus is pre-1.0. Fixes go into the latest release only.
