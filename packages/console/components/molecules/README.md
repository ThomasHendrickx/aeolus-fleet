# Molecules

Shared small compositions of atoms, used by two or more features; props only. Among them StatusBadge, ShipName, LocationTag, LiveStatus, EmptyState, InlineError, LoadingSkeleton, TypedConfirm (type the ship's name to confirm a retire that loses work), ConsequenceList (what a ship action will do, as facts), SendShortcutHint (the send shortcut's keys inside a Send button) and ReportLine (what a ship says it is doing: state, note and when, as a row or on the ship page). A molecule only one feature uses lives in that feature.
