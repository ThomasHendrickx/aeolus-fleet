# Molecules

Small compositions of atoms, props only: StatusBadge, ShipName, LocationTag, LiveStatus, EmptyState, InlineError, LoadingSkeleton, StartingPromptBlock, TypedConfirm (type the ship's name to confirm a retire that loses work), ConsequenceList (what a ship action will do, as facts), SelectorPicker (one ship by name or any ship of a type) and Sentence (a history sentence, its ships as ShipName).
