# Molecules

Small compositions of atoms, props only: StatusBadge, ShipName, LocationTag, LiveStatus, EmptyState, InlineError, LoadingSkeleton, TypedConfirm (type the ship's name to confirm a retire that loses work), ConsequenceList (what a ship action will do, as facts), SendShortcutHint (the send shortcut's keys inside a Send button), PingStatus (how a ship's last ping stands), ReportLine (what a ship says it is doing: state, note and when, as a row or on the ship page), SelectorPicker (one ship by name or any ship of a type) and Sentence (a history sentence, its ships as ShipName).
