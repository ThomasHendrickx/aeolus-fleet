# Molecules

Small compositions of atoms, props only: StatusBadge, ShipName, LocationTag, LiveStatus, EmptyState, InlineError, LoadingSkeleton, StartingPromptBlock, TypedConfirm (type the ship's name to confirm a retire that loses work), ConsequenceList (what a ship action will do, as facts), ShipActions (a ship's actions with their inline confirms) and Sentence (a history sentence, its ships as ShipName).
